# 핵심 패턴 치트시트 (백지 재현용)

> 시험장에서 **안 보고 손으로 쓸 수 있어야 하는 골격**만 모았다. 각 항목의 **고리(기억 포인트)** 를 먼저 떠올리고, 그 안을 채운다.
> 범위: 이벤트 처리 · 스피너 · Navigation · RecyclerView · SQLite(Room / OpenHelper)

---

## 0. 공통 시작 (ViewBinding)

```kotlin
private lateinit var binding: ActivityMainBinding
override fun onCreate(savedInstanceState: Bundle?) {
    super.onCreate(savedInstanceState)
    binding = ActivityMainBinding.inflate(layoutInflater)
    setContentView(binding.root)
}
```
- **Fragment**: `binding = XxxBinding.inflate(inflater, container, false)` → `return binding.root`
- id `btn_add` → 코드에서는 `binding.btnAdd` (카멜)

## 1. 이벤트 리스너 (위젯별 1개씩만 외우면 됨)

| 위젯 | 등록 | 람다 매개변수 |
|---|---|---|
| CheckBox/Switch | `setOnCheckedChangeListener` | `{ _, isChecked -> }` |
| RadioGroup | `setOnCheckedChangeListener` | `{ _, checkedId -> when(checkedId){...} }` |
| RatingBar | `setOnRatingBarChangeListener` | `{ _, rating, _ -> rating.toInt() }` |
| EditText | `addTextChangedListener(object: TextWatcher{...})` | 메소드 **3개** 재정의 |
| Button | `setOnClickListener` / `setOnLongClickListener` | 롱클릭은 **`true` 반환** |

```kotlin
binding.etMemo.addTextChangedListener(object : TextWatcher {
    override fun beforeTextChanged(s: CharSequence?, start: Int, count: Int, after: Int) {}
    override fun onTextChanged(s: CharSequence?, start: Int, before: Int, count: Int) {
        binding.tvCount.text = "${s?.length ?: 0} / 50"
    }
    override fun afterTextChanged(s: Editable?) {}
})
```
- **고리**: 체크박스는 상태 변수 두지 말고 **`isChecked` 직접 읽기**. 롱클릭 끝은 **`true`**. `Toast ... .show()` 의 **`.show()`** 잊지 말기.

## 2. 스피너 (ArrayAdapter + 리스너 공유)

```kotlin
val types = arrayOf("전체", "분실물", "습득물")
spinner.adapter = ArrayAdapter(this, android.R.layout.simple_spinner_item, types)

val listener = object : AdapterView.OnItemSelectedListener {
    override fun onItemSelected(parent: AdapterView<*>?, view: View?, position: Int, id: Long) {
        adapter.setFilters(spinnerA.selectedItemPosition, spinnerB.selectedItemPosition)
    }
    override fun onNothingSelected(parent: AdapterView<*>?) = Unit
}
spinnerA.onItemSelectedListener = listener
spinnerB.onItemSelectedListener = listener   // 하나를 두 스피너에 공유
```
- xml로 채우기: `android:entries="@array/..."`  (arrays.xml에 `<string-array>`)
- **고리**: 메소드 **2개 → `object :`** (람다 불가). `onNothingSelected` 필수. 리스너 안에서 **두 스피너 값 모두** 읽기.

## 3. Navigation (id 4곳 일치가 전부)

**맞출 id 4곳**: ① 메뉴 item `@+id/xxx` ② 그래프 `<fragment android:id="@+id/xxx">` ③ Fragment 클래스 ④ `AppBarConfiguration(setOf(...))`
→ **메뉴 id == 그래프 id** 이면 클릭 연결은 자동.

```kotlin
// NavHost 가 FragmentContainerView 면 FragmentManager 로 꺼낸다 (findNavController(id) 는 크래시)
val navController = (supportFragmentManager
    .findFragmentById(R.id.nav_host) as NavHostFragment).navController

appBarConfiguration = AppBarConfiguration(
    setOf(R.id.homeFragment, R.id.facilityFragment)     // 드로어면 뒤에 , drawerLayout
)
setupActionBarWithNavController(navController, appBarConfiguration)   // 제목 + Up
navView.setupWithNavController(navController)                        // 탭/메뉴 클릭 → 이동

override fun onSupportNavigateUp() =
    navController.navigateUp(appBarConfiguration) || super.onSupportNavigateUp()
```

**화면 간 데이터 전달 (action + bundle)**
```kotlin
// 보내는 쪽 (Fragment)
val bundle = bundleOf("facilityId" to "library")
view.findNavController().navigate(R.id.action_a_to_b, bundle)
// 받는 쪽
val id = arguments?.getString("facilityId") ?: "library"   // ?: 로 null 안전
```
- **고리**: 바텀탭 vs 드로어 차이는 **`AppBarConfiguration` 2번째 인자에 `drawerLayout`** 유무. 보낸 키 == 받는 키 (대소문자까지).
- 옵션 메뉴: `onCreateOptionsMenu`에서 `menuInflater.inflate(R.menu.xxx, menu)`, `onOptionsItemSelected`에서 `when(item.itemId)`.

## 4. RecyclerView (만들고·연결하고·개수)

```kotlin
class VH(val binding: ItemXBinding) : RecyclerView.ViewHolder(binding.root) {
    fun bind(item: X) {
        binding.tvTitle.text = item.title
        binding.tvBadge.visibility = if (item.important) View.VISIBLE else View.GONE  // 둘 다 지정
    }
}
class XAdapter(private val items: MutableList<X>,
               private val onClick: (X) -> Unit,            // 동작은 Activity 가 람다로 줌
               private val onLongClick: (X) -> Unit) : RecyclerView.Adapter<VH>() {

    override fun onCreateViewHolder(parent: ViewGroup, viewType: Int): VH {
        val b = ItemXBinding.inflate(LayoutInflater.from(parent.context), parent, false)  // parent, false
        return VH(b)
    }
    override fun onBindViewHolder(holder: VH, position: Int) = holder.bind(items[position])
    override fun getItemCount() = items.size
}
```
항목 클릭/롱클릭 (bind 안):
```kotlin
binding.root.setOnClickListener { onClick(item) }
binding.root.setOnLongClickListener { onLongClick(item); true }
```
화면 연결:
```kotlin
binding.recyclerView.layoutManager = LinearLayoutManager(this)  // GridLayoutManager(this, 2) = 2열
binding.recyclerView.adapter = adapter
```
- **고리**: **Create·Bind·Count** 3메소드. inflate 끝 **`parent, false`**. **layoutManager 안 주면 안 보임**. 리스트 바꾸면 `notifyDataSetChanged()`. 클릭 동작은 **어댑터가 아니라 람다로 외부 주입**.
- AlertDialog: `AlertDialog.Builder(this).setTitle().setMessage().setPositiveButton("확인", null).show()`

## 5-A. SQLite — Room (thread + Handler)

```kotlin
@Entity(tableName = "MEMO_T")
data class Memo(@PrimaryKey var id: Long = 0, var title: String = "", var createdAt: Long = 0)

@Dao interface MemoDao {
    @Query("SELECT * FROM MEMO_T ORDER BY createdAt DESC") fun getAll(): List<Memo>
    @Insert fun insert(m: Memo); @Update fun update(m: Memo); @Delete fun delete(m: Memo)
}

@Database(entities = [Memo::class], version = 1) abstract class AppDB : RoomDatabase() {
    abstract fun memoDao(): MemoDao
}

val db = Room.databaseBuilder(applicationContext, AppDB::class.java, "memo_db").build()
val dao = db.memoDao()

// DB는 작업 스레드, 화면은 메인 스레드
thread {
    dao.insert(memo)
    Handler(Looper.getMainLooper()).post { items.add(0, memo); notifyDataSetChanged() }
}
```
- **고리**: **DB는 `thread{}`, 화면은 `Handler(Looper.getMainLooper()).post{}`**. 정렬은 `@Query`의 `ORDER BY ... DESC`. `:변수`로 바인딩(`WHERE id = :memoId`).

## 5-B. SQLite — SQLiteOpenHelper (Contract + Cursor)

```kotlin
class DBHelper(c: Context?) : SQLiteOpenHelper(c, "contact.db", null, 1) {
    override fun onCreate(db: SQLiteDatabase) { db.execSQL(SQL_CREATE) }
    override fun onUpgrade(db: SQLiteDatabase, old: Int, new: Int) { db.execSQL(SQL_DROP); onCreate(db) }
}

// 쓰기: writableDatabase + ContentValues
val v = ContentValues().apply { put("NAME", name); put("PHONE", phone) }
db.insert("CONTACT_T", null, v)                 // 2번째 인자 null

// 읽기: readableDatabase + rawQuery + Cursor
val cur = db.rawQuery("SELECT * FROM CONTACT_T", null)
while (cur.moveToNext()) { val id = cur.getInt(0); val name = cur.getString(1) }
cur.close()                                     // 꼭 close

// 삭제
db.delete("CONTACT_T", "ID = ?", arrayOf(id.toString()))
```
- 메소드 시그니처(수기 1순위): `insert(table, nullColumnHack, values)` / `delete(table, where, whereArgs)` / `update(table, values, where, whereArgs)` / `rawQuery(sql, args)`
- **고리**: 쓰기=`writableDatabase`, 읽기=`readableDatabase`. Cursor는 `moveToNext()`·`getXxx(0부터)`·`close()`. `?` 자리 = `arrayOf(...)`.

## 6. 등록 = 수정 (함수 하나, null 분기)

```kotlin
fun showFormDialog(existingItem: Item?) {
    if (existingItem != null && existingItem.ownerId != currentUser) {   // 작성자 검사
        Toast.makeText(this, "작성자만 수정 가능", Toast.LENGTH_LONG).show(); return
    }
    // tvFormTitle = if (existingItem != null) "수정" else "등록"
    // existingItem != null 이면 폼에 기존 값 채우기
    val dialog = AlertDialog.Builder(this).setView(dialogBinding.root).create()
    btnSave.setOnClickListener {
        if (title.isEmpty()) { Toast(...); return@setOnClickListener }    // dismiss 안 함
        if (existingItem == null) adapter.addItem(new)                    // 등록
        else { existingItem.title = title; adapter.updateItem(existingItem) }  // 수정
        dialog.dismiss()
    }
    dialog.show()
}
```
- **고리**: **`existingItem == null` → 등록, 아니면 수정**. 제목 비면 **dismiss 하지 말고 return**. 수정 후 필터 반영하려면 `applyFilters()`.
